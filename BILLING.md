# GitHub Billing - Understanding Your Charges

## Common Sources of GitHub Charges

If you received a charge from "GitHub Inc" for $10, it could be from several sources:

### 1. **GitHub Copilot** ($10/month)
- **Individual subscription**: $10/month or $100/year
- AI-powered code completion tool
- Check if you have an active Copilot subscription

### 2. **GitHub Pro** ($4/month)
- Enhanced features for individual developers
- Advanced tools and insights

### 3. **GitHub Actions**
- Pay-as-you-go for minutes beyond free tier
- Check your Actions usage in repository settings

### 4. **GitHub Packages**
- Storage and data transfer charges
- Review your package usage

### 5. **Large File Storage (LFS)**
- Additional storage or bandwidth charges
- Check LFS usage in your repositories

### 6. **GitHub Sponsors**
- Sponsorships you may have set up for other developers
- Review your active sponsorships

## How to Check Your GitHub Billing

### Step 1: Access Billing Settings
1. Go to [GitHub.com](https://github.com)
2. Click on your profile picture (top-right corner)
3. Select **Settings**
4. Click **Billing and plans** in the left sidebar

### Step 2: Review Your Subscriptions
1. Under "Plans and usage", you'll see:
   - Current plan (Free, Pro, Team, Enterprise)
   - Active subscriptions (Copilot, etc.)
   - Usage-based billing items

### Step 3: Check Payment History
1. In Billing settings, click **Payment information**
2. Review **Payment history** to see all charges
3. Each charge will show:
   - Date
   - Description
   - Amount
   - Invoice link

### Step 4: Review Usage
1. Check **Usage this month** section
2. Review:
   - GitHub Actions minutes
   - Package storage
   - Git LFS data
   - Codespaces hours (if applicable)

## How to Cancel or Modify Subscriptions

### Cancel GitHub Copilot
1. Go to **Settings** → **Billing and plans**
2. Under **Subscriptions**, find **GitHub Copilot**
3. Click **Edit** or **Cancel subscription**
4. Follow the prompts to cancel
5. You'll have access until the end of your billing period

### Downgrade GitHub Pro
1. Go to **Settings** → **Billing and plans**
2. Under **Plans**, click **Edit** next to your current plan
3. Select **Free** plan
4. Confirm the change

### Cancel GitHub Sponsors
1. Go to **Settings** → **Billing and plans**
2. Click **Sponsors log** or **Sponsorships**
3. Find active sponsorships
4. Click to cancel individual sponsorships

## Still Can't Find the Charge?

### Contact GitHub Support
1. Visit [GitHub Support](https://support.github.com/contact)
2. Select **Account and billing** → **Billing**
3. Describe your issue
4. Include:
   - Charge amount ($10)
   - Date of charge
   - Last 4 digits of payment method
   - Transaction ID (if available)

### Check Email Receipts
- GitHub sends email receipts for all charges
- Search your email for "github.com" or "GitHub Invoice"
- Check spam/junk folders

### Review Organization Memberships
- You might be a member of a paid organization
- Check: **Settings** → **Organizations**
- Organization owners may have billing enabled

## Preventing Unexpected Charges

### Set Up Spending Limits
1. Go to **Settings** → **Billing and plans**
2. Under **Spending limits**, set limits for:
   - GitHub Actions
   - GitHub Packages
   - Codespaces
3. Set to $0 to only use free tier

### Enable Billing Alerts
1. In Billing settings, enable email notifications
2. Get alerts when approaching spending limits
3. Monthly usage summaries

### Review Subscriptions Regularly
- Check billing settings monthly
- Cancel unused subscriptions
- Review team/organization access
